# NPB野球 海外の反応まとめサイト

> カテゴリ: 事業
> 作成日: 2026-02-11
> ステータス: アイデア段階

---

## 概要

Reddit（r/NPB, r/baseball等）の海外野球ファンの投稿・コメントをAIで翻訳・キュレーションし、2chまとめ風の読みやすい記事として配信するサイト。国内スポーツニュースのAI要約や、毎日の試合結果レポートも掲載する。既存の野球アンテナサイトの「広告過多で読みにくい」というUX課題を、適度な広告量とクリーンなデザインで解決する。

---

## 5W1H

### What（何を）

NPB・MLB日本人選手・国際大会に関する、以下3種類のコンテンツを自動生成・配信するWebメディア。

1. **海外の反応記事**: Redditの投稿を翻訳し、興味深い・面白い・皮肉の効いたコメントを2chまとめ風にキュレーション
2. **国内ニュース要約**: スポーツニュースをAIで要約し、Yahooニュースのコメントから議論のポイントを抽出
3. **デイリー試合結果レポート**: 毎日23時頃に自動投稿。試合結果、活躍した選手、出来事、順位変動グラフを含む

### Why（なぜ）

- 既存の野球アンテナ/まとめサイトは**広告が過剰**で、ユーザー体験が著しく悪い
- 「海外ファンがNPBをどう見ているか」を届ける**NPB特化の海外の反応サイトがほぼ存在しない**
- 野球ファンは日常的に情報を追うため、**リピーターになりやすい**
- LLMの翻訳・要約能力を活かせば、低メンテナンスでコンテンツ生成を自動化できる

### Who（誰が）

- **メインターゲット**: NPBファン（20〜40代男性が中心）
- **サブターゲット**: MLB日本人選手を追っているファン、海外の反応コンテンツが好きな層
- 運営者自身（横浜DeNAベイスターズファン）が最初のユーザー

### When（いつ）

- MVP: 2026年3月中（NPBシーズン開幕前に公開したい）
- コメント機能: PVが安定した段階で追加（2026年夏頃の想定）

### Where（どこで）

- Webサイト（PC/スマホ対応、レスポンシブ）
- X（Twitter）で記事投稿通知（無料枠: 月500投稿）

### How（どうやって）

- **記事生成**: Reddit API / ニュースRSS → LLM（翻訳・要約・キュレーション）→ microCMS API で自動投稿
- **試合結果**: スコアデータ取得 → LLM でレポート生成 → 順位データをJSON形式でmicroCMSに投稿 → フロント側でChart.jsレンダリング
- **定時実行**: 余剰MacBookを常時稼働させ、crontab + Claude Code（MAXプラン）で定時実行。モデルはSonnet 4.5またはOpus 4.6を使用
- **X投稿**: 記事公開時にX API（Free tier）で自動投稿

## 実現可能性

### 技術的実現可能性: 容易

Next.js + microCMS の構成は清水さんのメイン技術スタックそのもの。Reddit APIからのデータ取得スクリプトも既にknowledge-hubプロジェクトで実績がある。LLMによる翻訳・要約もClaude Code運用経験があるため、新たに学習が必要な技術はほぼない。

### コスト: 無料

| 項目 | 費用 | 備考 |
|------|------|------|
| Vercel（ホスティング） | 無料 | Hobby プラン |
| microCMS | 無料〜 | 無料枠: API 3つ、コンテンツ10,000件 |
| Supabase（将来） | 無料 | コメント機能追加時 |
| ドメイン | 年1,000〜2,000円 | 独自ドメイン取得 |
| LLM | 無料 | Claude MAX プラン内で運用（追加費用なし） |
| 実行環境 | 無料 | 余剰MacBookを常時稼働サーバーとして使用 |
| **合計** | **実質無料** | ドメイン代のみ |

※ LLMはClaude MAXプランのSonnet 4.5（またはOpus 4.6）を使用。記事生成パイプラインはClaude Code Skill として実装し、余剰MacBook上でcrontabによる定時実行で自動化する。

### 差別化: 高い

- **NPB特化の海外の反応サイト**はほぼ存在しない（既存サイトはMLB中心）
- 既存の野球アンテナサイトは広告過多でUXが劣悪。**適度な広告量 + クリーンなUI**だけで相対的に優位
- AI要約 + コメントキュレーションによる**読みやすさ**が差別化要因
- デイリー試合結果レポート（順位変動グラフ付き）は独自コンテンツとして強い

### 需要（Dogfooding）: 高い

運営者自身が横浜DeNAベイスターズファンであり、NPBを日常的に追っている。「海外ファンがベイスターズをどう見ているか」は純粋に知りたい情報。自分が毎日見たいサイトを作る、という強い動機がある。

### 工数: 中（目安: 2〜3週間）

MVP（記事表示 + カテゴリ/タグ/検索 + 記事生成パイプライン）は2〜3週間で構築可能。コメント機能はMVP外とすることで初期工数を抑える。

## リスクと懸念事項

- **Redditコンテンツの著作権**: Redditの投稿・コメントを翻訳して転載する形になるため、著作権のグレーゾーン。対策として、元投稿へのリンクを必ず掲載し、引用の範囲内にとどめる。DMCA対応のポリシーページも用意する
- **AI生成コンテンツのSEO評価**: GoogleはAI生成コンテンツを低評価する傾向がある。対策として、単純な機械翻訳ではなく、キュレーション（コメント選別・構成）で独自性を出す。タイトルや導入文は人間が監修する運用も検討
- **r/NPBのコンテンツ量**: オフシーズンはRedditの投稿が減る可能性がある。対策として、国内ニュース要約とデイリー試合結果でカバーし、コンテンツの空白を防ぐ
- **MAXプランの利用制限**: 記事生成量が多い場合、MAXプランの日次/月次利用制限に抵触する可能性がある。対策として、1日の生成記事数を制御し、制限内に収まる運用設計にする。万一制限超過が常態化した場合はAPI課金への移行も検討

## MVP 定義

### スコープ

- [ ] Next.js + microCMS でサイト基盤構築（カテゴリ別一覧、タグ、検索、記事詳細）
- [ ] Reddit記事の翻訳・キュレーション記事生成パイプライン
- [ ] 国内ニュース要約記事生成パイプライン
- [ ] デイリー試合結果レポート生成パイプライン（順位変動グラフ付き）
- [ ] レスポンシブデザイン（PC/スマホ対応）
- [ ] Google AdSense 導入
- [ ] SEO基本対策（メタタグ、OGP、sitemap、構造化データ）

### スコープ外（将来対応）

- コメント機能（Supabase + ユーザー認証 + 通報/自治システム）
- X（Twitter）自動投稿連携
- RSS配信
- ダークモード
- お気に入り・ブックマーク機能
- プッシュ通知

## 技術スタック（案）

| レイヤー | 技術 | 選定理由 |
|----------|------|----------|
| フロントエンド | Next.js (App Router) | メイン技術スタック。SSG/ISRでパフォーマンスとSEOを両立 |
| CMS | microCMS | 日本製ヘッドレスCMS。API経由での記事投稿が容易で自動化と相性が良い |
| グラフ描画 | Chart.js / Recharts | microCMSのJSONデータからクライアントサイドで順位変動グラフを描画 |
| ホスティング | Vercel | Next.jsとの統合が最適。無料枠で運用可能 |
| DB（将来） | Supabase | コメント機能追加時に導入。認証・RLS・リアルタイム機能が組み込み済み |
| 記事生成 | Claude Code (MAXプラン) | Sonnet 4.5 / Opus 4.6 で翻訳・要約・キュレーション。Skill として実装 |
| 実行環境 | 余剰MacBook + crontab | 常時稼働サーバーとして定時実行。追加コスト無し |
| データ取得 | Python スクリプト | Reddit API、ニュースRSS、スコアデータの取得 |
| 広告 | Google AdSense | 収益化。広告量は控えめに設定 |
| SNS連携（将来） | X API (Free tier) | 記事公開通知。月500投稿まで無料 |
