## 概要

Claude Code を活用した WordPress ホームページ制作を副業として展開する。業種別テンプレートを事前に用意し、テンプレートベースの制作サービスとしてココナラ等のプラットフォームで販売する。月10万円の利益を目標とする。

## 5W1H

### What（何を）

WordPress を使った小規模事業者向けホームページ制作サービス。業種別のテンプレートを事前に作成しておき、顧客のヒアリングシートに基づいてカスタマイズ・納品する。

**テーマ設計の理念**:

> 顧客のITリテラシーが限界まで低くても、直感的にコンテンツ更新ができること。
> また、WordPressのバージョン依存が可能な限り少ないこと。

この理念に基づき、テーマは以下の方針で設計する:
- **直感的な更新**: WordPress 標準のブロックエディタ（Gutenberg）で全てのコンテンツを編集可能にする。カスタムフィールドやショートコードなど、顧客が理解しにくい仕組みは使わない
- **シンプルな管理画面**: 不要なメニューや設定項目を非表示にし、顧客が迷わない管理画面を提供する
- **バージョン依存の最小化**: WordPress コア機能と標準 API のみを使用し、特定バージョンに依存するコードを避ける。プラグインへの依存も最小限にする（Contact Form 7 等の定番プラグインに限定）
- **顧客用ロールによる保護**: 納品時に顧客用の専用ロール（「編集者」ベースのカスタムロール）を設定し、コンテンツ更新に必要な権限のみを付与する。テーマ編集、プラグイン管理、コードエディタなど、テーマを破壊しうる操作は制限する。管理者アカウントのパスワードは納品時に顧客に渡すが、通常運用では顧客用ロールの使用を推奨する

### Why（なぜ）

- 副収入として月10万円を安定的に確保したい
- フロントエンド + WordPress のスキルを直接マネタイズできる
- Claude Code による自動化で、制作原価（自分の作業時間）を圧縮し、副業でも回せるビジネスモデルにする

### Who（誰が）

**ターゲット顧客**:
- 個人店舗（飲食店、美容院、整体院 等）
- 中小企業（5〜20名規模）
- 「自分でホームページを作れない・作る時間がない」人

**提供者**: 清水陽平（SilMo）- フリーランスフロントエンドエンジニア

### When（いつ）

- **準備期間**: 2026年3月〜4月（約2ヶ月）
- **フェーズ1（ココナラで実績作り）**: 2026年5月〜6月
- **フェーズ2（販促サイト構築・直接受注開始）**: 2026年7月〜
- **稼働時間**: 平日夜間 + 土日（1日4時間）

### Where（どこで）

**受注チャネル**:
- フェーズ1: ココナラ（手数料22%）
- フェーズ2: 販促サイト（wp.silmo.jp）からの直接受注を並行
- フェーズ3: 直接受注をメインに、ココナラは新規流入チャネルとして維持

**制作環境**:
- ローカル: Docker Compose + WP-CLI
- デモサイト: Xサーバー（wp.silmo.jp）
- コード管理: GitHub

### How（どうやって）

**制作フロー（1案件あたり実作業1〜2日 / 4h稼働）**:

```
受注
 ↓
ヒアリングシート送付 → 顧客記入（待ち時間）
 ↓
[Day 1: 4h]
├── 顧客専用リポジトリ作成（GitHub Template Repo から生成）
├── Claude Code スキル発動 → ヒアリングシート読み込み
├── テンプレートコピー → カスタマイズ実装
└── セルフレビュー + 微調整
 ↓
[Day 2: 4h]
├── プレビュー環境で顧客にレビュー依頼
├── 修正対応（最大3回）
├── 顧客サーバーに直接デプロイ
└── 動作確認 + パスワード変更依頼 + クロージング
```

※ 顧客の応答待ち時間を含めた暦上の納期目安は5日〜

**Claude Code 活用の核心**:
- テーマ開発用リポ（`wp-templates`）: テンプレート作成・管理
- 顧客案件用リポ（`wp-client-template` から複製）: 案件ごとのカスタマイズ
- `/customize-theme` スキル: ヒアリングシートを読み込み、テーマを自動カスタマイズ

## 実現可能性

### 技術的実現可能性: 容易

WordPress テーマ開発はフロントエンド（HTML/CSS/JS）+ PHP で完結し、メインスキルセットの範囲内。Claude Code との連携も WordPress 公式プラグイン（Claude Cowork）が 2026年2月にリリースされており、エコシステムが整いつつある。

### コスト: 低コスト

| 項目 | 月額 | 備考 |
|------|------|------|
| Xサーバー | 0円 | 既存契約を活用 |
| ドメイン（wp.silmo.jp） | 0円 | サブドメインで対応 |
| Docker / Claude Code | 0円 | ローカル環境 |
| ココナラ手数料 | 売上の22% | フェーズ1のみ。直接受注に移行すれば削減 |
| Stripe 手数料 | 売上の3.6% | フェーズ2以降の直接受注時 |

初期投資はほぼゼロ。ランニングコストもココナラ手数料のみ。

### 差別化: 中程度

ココナラの WordPress 制作市場は競合が非常に多い（上位出品者は評価100〜300件超）。ただし以下の差別化ポイントがある:

- **テンプレートベースの明確な完成イメージ提示**: デモサイト（wp.silmo.jp）で実物を見せられる
- **Claude Code による爆速納品**: 実作業1〜2日は競合より明らかに速い
- **「おまかせオプション」**: 素材・文章をAI生成で賄い、顧客の手間を最小化

ただし「業種特化」まで絞り込めれば差別化は「高い」に近づく。

### 需要（Dogfooding）: 低い

自分自身が使うサービスではなく、他者への提供が目的。ただし「副収入月10万」という明確な金銭的モチベーションがあり、Dogfooding の代替動力として十分。

### 工数: 大（目安: 2ヶ月）

準備フェーズの工数内訳:

| タスク | 工数目安 |
|--------|---------|
| テンプレート作成（3〜4業種分） | 3〜4週間 |
| 開発環境・自動化基盤の構築 | 1週間 |
| デモサイト構築（wp.silmo.jp） | 3〜4日 |

副業の稼働時間（平日夜間+土日）で約2ヶ月。

## リスクと懸念事項

- **実績ゼロの壁**: ココナラでは実績数が信頼の指標。最初の5件を獲得するまでが最もハードルが高い。対策: デモサイトで完成イメージを提示し、初期は若干の値引きで実績を積む
- **顧客対応の時間コスト**: 制作以外のコミュニケーション（質問対応、素材催促、修正指示の曖昧さ）が想定以上に時間を食うリスク。対策: ヒアリングシートの項目を絞り込み、修正回数を3回に制限。自由記入欄には追加料金の注意書きを入れる
- **サーバー認証情報の取り扱い**: 顧客のサーバーに直接アクセスするため、セキュリティインシデント（誤操作、情報漏洩）のリスクがある。対策: 作業完了後にパスワード変更を必ず依頼。作業中の認証情報は `.env` で管理し、Git に含めない
- **AI生成コンテンツの品質**: 「おまかせオプション」でAI生成した文章・画像が顧客の期待に合わない可能性。対策: 店舗の実写真はフリー素材 or 顧客撮影を推奨。AI生成は装飾的な要素に限定する
- **本業との両立**: 平日夜間+土日の稼働は体力的に負担。月3件以上に増やすと品質低下のリスク。対策: 月3件を上限とし、無理な受注はしない

## 技術スタック（案）

| レイヤー | 技術 | 選定理由 |
|----------|------|----------|
| CMS | WordPress | ターゲット顧客との親和性が高く、市場需要が最も大きい |

## 事業開始前の準備ロードマップ

### Phase 0: 環境構築（1週間）

1. Docker Compose で WordPress ローカル開発環境を構築
2. WP-CLI を導入・動作確認
3. GitHub に `wp-templates` リポジトリを作成
4. GitHub に `wp-client-template`（Template Repo）を作成
5. Claude Code の CLAUDE.md を作成（テーマ開発の規約・方針を定義）

### Phase 1: テンプレート作成（3〜4週間）

6. 飲食店テンプレートの設計（ページ構成、カラースキーム、レイアウト）
7. Claude Code を使ってテーマを実装
8. レスポンシブ対応・ブラウザテスト
9. 「お知らせ（ブログ）」「お問い合わせフォーム」の ON/OFF 機能を実装
10. `/customize-theme` スキルの作成・テスト

### Phase 2: デモサイト公開（3〜4日）

11. Xサーバーに WordPress マルチサイトを構築（wp.silmo.jp）
12. 飲食店テンプレートのデモサイトを公開（wp.silmo.jp/restaurant）
13. デモサイトのスクリーンショットを撮影

### Phase 3: 業務テンプレート整備（2〜3日）

14. ヒアリングシート（MD形式）を作成
15. `wp-client-template` リポに業務テンプレート一式を整備
16. 受注〜納品のワークフローを一通り自分でテスト（ダミー案件でリハーサル）

### Phase 4: 出品・営業開始（2〜3日）

17. ココナラアカウント作成・プロフィール設定
18. 出品ページ作成（タイトル、説明文、価格、デモサイト URL、サービス内容）
19. 出品公開 → 運用開始
