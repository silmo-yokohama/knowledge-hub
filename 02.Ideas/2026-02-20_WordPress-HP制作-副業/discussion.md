# 壁打ち記録: WordPress ホームページ制作 副業

> 実施日: 2026-02-20
> 参加者: 清水陽平 / Claude

---

## 対話ログ

### ラウンド1: アイデアの概要

**清水**: ホームページ制作で副業をしたい。月10万ほどの利益が目標。ココナラ等のプラットフォームで案件を獲得する想定。ホームページ制作の実績はない（自分のサイトのみ）がスキルはある。サーバー・ドメインは客側に用意してもらい、WordPress を使ったホームページ制作を行う。単価は3〜5万を想定。差別化として Claude Code を使ってデザイン提案と実装をほぼ自動化し、スピード感で勝負したい。ただし副業なので平日夜間と土日しか稼働できない。

**Claude**: スキルセット（フロントエンド + PHP/WordPress）は十分だが、3つの懸念を指摘:
1. **単価3〜5万は最激戦区**で実績ゼロだと埋もれる
2. **デザイン特化でない**と低単価競争に巻き込まれる
3. Claude Code の速度は顧客には見えない内部優位性

代替案として「業種特化 × テンプレート戦略」を提案。業種別テンプレートを事前に用意し、「テンプレートから選んでカスタマイズ」という形にすることで、デザイン力不要 + 納品スピード向上 + 完成イメージの事前提示が可能になる。

---

### ラウンド2: テンプレート販売 vs 制作サービス

**清水**: テンプレートのZip販売（テーマ単体販売）に興味がある。ココナラで需要はあるか？

**Claude**: テーマ Zip 販売はココナラでは需要が薄い。理由:
- ThemeForest 等の専門マーケットが強い
- ココナラのユーザー層は「全部やってほしい人」が大半
- テーマ単体で3〜5万は海外テーマ（$50前後）と比較されて厳しい

テンプレートは**販売する商品ではなく、自分の作業効率を上げるための武器**として使う「テンプレートベースの制作サービス」を提案。顧客にはテンプレートのプレビューを見せて選んでもらい、裏側でテンプレートを活用して爆速納品する形。

**清水**: その方針で行く。

---

### ラウンド3: 業務フロー・開発環境・プロンプト設計の深掘り

**清水**: 業務フローをもっと詰めたい。

**Claude**: 全体フロー（準備 → 受注 → 制作 → 納品後）を整理し、3つのボトルネックを指摘:
1. **素材の受け取り方**: 顧客から素材が来ないケースが最大のボトルネック
2. **修正回数の上限**: 低単価で無制限修正はNG
3. **サーバー・ドメイン設定の線引き**: 顧客に全部やらせるのは現実的に厳しい

**清水**: 素材はテンプレート化したい。こだわりのない顧客向けに「おまかせオプション」（AI生成テキスト + フリー素材/AI画像）も用意したい。修正は3回。サーバーは客側で用意してもらい、認証情報は預かりたくない。

**Claude**: おまかせオプションは良い差別化になるが、AI生成画像は店舗の実写真には不向き（「サイトと実物が違う」問題）。フリー素材 or 顧客撮影を推奨。修正3回は妥当。サーバーについては3方式を比較し、認証情報を預からない「ステージング → 画面共有で移行」方式を提案。

---

### ラウンド4: 4つの重要テーマの深掘り

**清水**: 以下の4点を詰めたい:
1. 開発環境をどうするか
2. Claude Code のプロンプト設計
3. テンプレートの管理と公開方法
4. 価格帯の設定（競合リサーチ希望）

**Claude**: 競合リサーチの結果、ココナラ上位出品者の最安ラインは7〜8万円（評価100件超）。**3〜5万は安すぎる**と指摘し、初期価格5万円 → 軌道後8万円を提案。

開発環境は Docker Compose + WP-CLI を推奨（CLIベースで Claude Code と相性が良い）。プロンプト設計は2層構造（プロジェクト共通 CLAUDE.md + 案件ごとのスキル）。テンプレート管理は GitHub リポジトリ + Xサーバーでデモサイト公開。

---

### ラウンド5: ヒアリングシート設計

**清水**: ヒアリングシートの項目を決めたい。

**Claude**: 4セクション（基本情報 / サイトの要望 / 素材 / サーバー情報）+ SEO セクションの5セクション構成を提案。

**清水**: SEO関連のヒアリングはあってもいい。ただし「雰囲気・イメージ」「参考URL」はテンプレートベースなのに聞く必要があるのか？必要ページもテンプレートに合わせるので選択は不要では？ブログとお問い合わせは ON/OFF オプションがあるといい。

**Claude**: 鋭い指摘。テンプレートベースなのに自由度の高い質問はスコープが膨らむ原因になる。雰囲気・参考URL・ページ構成を削除し、テンプレートに流し込む情報だけに絞った改訂版を提示。記入項目数を約20→約16に削減、自由記入欄も最小化。

---

### ラウンド6: 受注チャネル拡大と最終調整

**清水**: ココナラ以外からの受注も増やしたい。テンプレート販促用サイトを作って直接依頼を受けたい。「その他のご要望」の自由入力欄はあってもいい。

**Claude**: 直接受注は利益率を大きく変える（ココナラ手数料22% vs Stripe 3.6%、月3件で年間30万以上の差）。フェーズ分けを提案: フェーズ1でココナラ実績作り → フェーズ2で販促サイト構築 → フェーズ3で直接受注メインに移行。販促サイト自体が「WordPress 制作の実績」になる点も指摘。

---

### ラウンド7: ワークフロー確定と企画書作成依頼

**清水**: 実装→納品は実作業1〜2日（4h/日）で行いたい。詳細なフローを提示:
受注 → ヒアリングシート → 顧客専用ワークスペース作成 → Claude Code スキル → テンプレートコピー → 実装 → レビュー → 修正3回まで → デプロイ

納品方法は「サーバーに直接構築」に変更（折衝を減らすため）。パスワードは完了後に変更依頼。

テンプレート管理リポと顧客ワークスペースリポでシステムプロンプト・スキルは分ける。デモサイトは自前の Xサーバー（wp.silmo.jp/{テーマ名}）を活用。

事業開始前に何をどの順番で準備するかをまとめ、企画書を作成してほしい。

## 議論のまとめ

### アイデアの変遷

1. **初期**: ココナラで WordPress ホームページ制作。単価3〜5万、デザイン非特化、スピード勝負
2. **深掘り後**: テンプレートベースの制作サービスに転換。業種特化テンプレートを事前作成し、Claude Code で自動化。単価5万→8万へ段階的に引き上げ
3. **最終形**: 2リポジトリ構成（テンプレート管理 + 顧客案件）で開発基盤を整え、ココナラ → 自社販促サイトへの段階的チャネル移行。ヒアリングシートを極限まで絞り込み、実作業1〜2日（4h/日）で回すビジネスモデル

### 主要な論点

- **単価設定**: 3〜5万 → 5万（初期）→ 8万（軌道後）に修正。ココナラ上位の最安ラインが7〜8万のため、最初から安売りしすぎない
- **テンプレート販売 vs 制作サービス**: Zip販売は需要薄。テンプレートは内部の効率化手段として使い、制作サービスとして提供する
- **納品方式**: 認証情報を預からない方式 → 折衝コスト削減のため直接構築方式に変更。パスワードは事後変更を依頼
- **ヒアリングシートの設計**: テンプレートベースの前提に合わない自由度の高い項目を削除。流し込み情報に特化
- **受注チャネル**: ココナラ一本 → 販促サイト（wp.silmo.jp）での直接受注を並行。手数料削減で年間30万以上の差

### 出たフィードバック

#### 肯定的な評価

- Claude Code による自動化は「スピード」だけでなく「原価圧縮」という構造的優位性になる
- フロントエンド + WordPress の掛け算スキルは副業向きの強力な基盤
- テンプレートベースの制作はデザイン力不要で、副業の時間制約とも相性が良い
- 「おまかせオプション」は素材を用意できない顧客層への差別化になる
- 販促サイト自体が WordPress 制作の実績になる（実績ゼロ問題の部分的解決）

#### 指摘事項と対応

| 指摘内容 | 対応方針 |
|----------|----------|
| 単価3〜5万はココナラ最激戦区で実績ゼロだと埋もれる | 初期5万、軌道後8万に修正 |
| デザイン特化でないと差別化が弱い | 業種特化テンプレート戦略で回避 |
| AI生成画像は店舗実写と乖離するリスク | 実写系はフリー素材/顧客撮影、AI生成は装飾のみ |
| 顧客にサーバー設定を全部やらせるのは非現実的 | 直接構築方式に変更 |
| ヒアリングシートの自由記入欄が多いとスコープが膨らむ | 流し込み情報に特化した改訂版を採用 |

### 未解決の課題

- テーマのデザイン（ワイヤーフレーム・カラースキーム）は未着手
- ココナラの出品ページの具体的な文面・訴求ポイント
- 「おまかせオプション」の追加料金設定
- 確定申告・税務上の扱い（副業所得の申告方法）
- 万一のトラブル時の対応方針（納品後の不具合、クレーム等）
