## 使えそうな技術・ライブラリ

- [Docker Compose](https://docs.docker.com/compose/): WordPress ローカル開発環境の構築。CLI 完結で Claude Code との相性が良い
- [WP-CLI](https://wp-cli.org/ja/): WordPress のコマンドライン管理ツール。テーマインストール、設定変更を自動化
- [All-in-One WP Migration](https://ja.wordpress.org/plugins/all-in-one-wp-migration/): WordPress サイトのエクスポート/インポート。ローカル→本番環境への移行に使用
- [WordPress マルチサイト](https://ja.wordpress.org/documentation/article/create-a-network/): 1つの WordPress インストールで複数サイトを管理。デモサイト運用に適している
- [Stripe](https://stripe.com/jp): オンライン決済プラットフォーム。個人でも導入可能、手数料3.6%。直接受注フェーズで使用
- [Claude Cowork Plugin](https://wordpress.com/blog/2026/02/13/new-plugin-and-skills-for-claude-cowork/): WordPress 公式の Claude 連携プラグイン。テーマ生成の効率化に活用可能
- [Unsplash](https://unsplash.com/): 高品質フリー素材写真。「おまかせオプション」での素材提供に使用
- [Contact Form 7](https://ja.wordpress.org/plugins/contact-form-7/): WordPress の定番お問い合わせフォームプラグイン
